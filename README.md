## About the Project
This repository was created while learning the **CSS Flexible Box Layout** module. Each HTML file isolates a specific Flexbox property (like `justify-content`, `align-items`, `flex-wrap`, etc.) so you can see exactly how it behaves.

- **Developer:** Haluk Can SARIÖZ
- **Purpose:** Learn and practice CSS Flexbox
- **Format:** Standalone HTML files with embedded CSS

---

## What You'll Learn
- Using `display: flex` to create flexible containers
- Controlling main-axis alignment with `justify-content`
- Controlling cross-axis alignment with `align-items` and `align-content`
- Changing item order with `order`
- Distributing space with `flex-grow`, `flex-shrink`, and `flex-basis`
- Wrapping items onto multiple lines with `flex-wrap`
- Building simple responsive layouts without floats or positioning

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/halukcansarioz/Simple-Flex-Layout.git
```

### 2. Navigate to the folder
```bash
cd Simple-Flex-Layout
```

### 3. Open any example in your browser
You can simply double‑click any `.html` file, or use a live server (e.g., VS Code Live Server) for a better experience:
```bash
open flexbox-basics.html   # macOS
start flexbox-basics.html  # Windows
```
